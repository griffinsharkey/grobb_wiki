# The Gatehouse

## Introduction
In a remote region of Grobb, an ancient castle now ruined shadows a small brewing town. All that remains of the surface structure is a lone gatehouse atop a cliff. What lies underneath is yet to be discovered.

## The Game
The Gatehouse is played using the Shadowdark rpg. It is mostly an introduction to OSR principles and old-school dungeon crawling. Shadowdark is a modern take on old school gaming. The campaign is using David Bezio's *Sword and Wizardry* module *The Gatehouse on Cormac's Crag*.
